Built for AI agents

Blowfish ships an agent skill that teaches Claude Code and other coding agents how to install, configure, and build with the theme.
Install the skill

Blowfish v3.5 is available. Start a new site with npx blowfish-tools new <site> or upgrade an existing site.

Working with a coding agent? In Claude Code, run /plugin marketplace add nunocoracao/blowfish, then /plugin install blowfish@blowfish. For another agent that reads project skills, copy the blowfish skill folder into your site at .claude/skills/blowfish/.
